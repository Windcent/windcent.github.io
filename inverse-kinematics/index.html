Inverse Kinematics (x, y → θ1, θ2)

1. Radial Distance & Workspace Check
r = √x² + y² ,  |L1 − L2| ≤ r ≤ L1 + L2
r = 0.000
2. Elbow Angle θ2 (Law of Cosines)
cos(θ2) = x² + y² − L1² − L2² 2 · L1 · L2
θ2 = atan2(± √1 − cos²(θ2) , cos(θ2))
cos(θ2) = 0.000 ⇒ θ2 = 0.00°
3. Shoulder Angle θ1
θ1 = atan2(y, x) − atan2(L2 sin(θ2), L1 + L2 cos(θ2))
θ1 = 0.00° − 0.00° = 0.00°

Forward Kinematics (θ1, θ2 → x, y)

1. Elbow Joint Position (x1, y1)
x1 = L1 cos(θ1),  y1 = L1 sin(θ1)
(x1, y1) = (0.000, 0.000)
2. End-Effector Position (x, y)
x = L1 cos(θ1) + L2 cos(θ1 + θ2)
y = L1 sin(θ1) + L2 sin(θ1 + θ2)
(x, y) = (0.000, 0.000)
3. Manipulator Jacobian Determinant
det(J) = L1 · L2 · sin(θ2)
det(J) = 0.000 (NON-SINGULAR)
