Stage 1 — Remote Speed Command Integration (ux, uy -> x, y)

1. Remote Speed Command
v_max = delta_max / dt;
vx = ux * v_max;  vy = uy * v_max;
2. Target Coordinate Integration
x = x + vx * dt;  y = y + vy * dt;

Stage 2 — Inverse Kinematics (x, y -> theta2, theta1)

3. Elbow Angle theta2 (Law of Cosines)
cos_t2 = (x*x + y*y - L1*L1 - L2*L2) / (2.0 * L1 * L2);
sin_t2 = elbow_sign * sqrt(1.0 - cos_t2*cos_t2);
theta2 = atan2(sin_t2, cos_t2);
cos_t2 = 0.000, sin_t2 = 0.000 => theta2 = 0.00 deg
4. Shoulder Angle theta1
theta1 = atan2(y, x) - atan2(L2 * sin(theta2), L1 + L2 * cos(theta2));
theta1 = 0.00 - 0.00 = 0.00 deg

Stage 3 — Forward Kinematics & Output Verification (theta1, theta2 -> Arm Pose)

5. Elbow Joint Position (x1, y1)
x1 = L1 * cos(theta1);  y1 = L1 * sin(theta1);
x1 = 0.000, y1 = 0.000
6. End-Effector Output Position (x, y) & Jacobian
x = L1 * cos(theta1) + L2 * cos(theta1 + theta2);
y = L1 * sin(theta1) + L2 * sin(theta1 + theta2);
det_J = L1 * L2 * sin(theta2);
x = 0.000, y = 0.000
det_J = 0.000 (NON-SINGULAR)
